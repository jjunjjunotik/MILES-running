# NailSense · AI 손톱 관찰 도우미

사진에 보이는 손톱의 **겉모습**을 정리해 주는 모바일 웹 앱입니다.
Claude 비전 모델이 6개 항목을 관찰해 설명하고, 일반적인 생활 관리 팁을 제안하며,
기록을 날짜별로 쌓아 변화를 비교할 수 있게 해 줍니다.

> **이 앱은 의료기기가 아닙니다.** 질병을 진단하거나 치료법을 안내하지 않습니다.
> 사진 한 장으로는 의학적 판단을 할 수 없으며, 결과는 참고용입니다.
> 변화가 이어지거나 다른 증상이 함께 있다면 의료 전문가와 상담하세요.

## 화면

| 화면 | 하는 일 |
|---|---|
| 홈 | 인사, 최근 관찰 요약, 지표 추이, 사진 처리 방식 안내 |
| 손톱 스캔 | 촬영/업로드, 부위 선택, 메모, 촬영 가이드, 분석 실행 |
| 결과 | 공유용 카드, 관찰 지표, 항목별 관찰과 AI 설명, 생활 팁, 전문가 상담 신호 |
| 기록 | 부위 필터, 관찰 지표 추이, 날짜별 목록과 이전 대비 변화, 삭제 |
| 프로필 | 닉네임, 사진 저장 여부 등 설정, 데이터 삭제, 개인정보 처리 안내 |

## 진단하지 않도록 만든 방법

안전 문구를 덧붙이는 데 그치지 않고, 구조에서부터 진단이 나올 자리를 없앴습니다.

- **스키마에 병명 칸이 없습니다.** 모델이 채우는 필드는
  `observation`(사진에서 보이는 것)과 `explanation`(일반적인 교육 정보)뿐입니다.
  질환·진단·치료 필드가 존재하지 않습니다. → `shared/analysis.ts`, `server/schema.ts`
- **상태값은 중증도가 아닙니다.** `good` / `watch` / `consult` 는
  "얼마나 신경 써서 지켜볼 만한가"를 뜻하며, `consult` 는
  "사진만으로는 판단이 어려우니 직접 보여 주는 편이 낫다"는 의미입니다.
- **시스템 프롬프트가 병명·치료·불안 조성 표현을 금지합니다.** → `server/prompt.ts`
- **관찰 지표(0~100)는 건강 점수가 아닙니다.** 같은 환경에서 찍은 사진끼리
  변화를 비교하기 위한 참고 수치라고 화면마다 명시합니다.
- **팁은 누구에게나 무해한 생활 습관 수준으로 제한합니다.**
  영양제 용량, 약물, 시술은 프롬프트와 스키마 설명 양쪽에서 금지합니다.
- **손톱이 아니거나 관찰이 어려운 사진은 결과를 만들지 않고 다시 찍도록 안내합니다.**

## 사진과 개인정보

- 계정과 로그인이 없습니다.
- 분석 기록과 사진은 **브라우저의 IndexedDB**에만 저장됩니다. 서버는 보관하지 않습니다.
- 업로드 전에 캔버스로 재인코딩해 **EXIF 메타데이터(촬영 위치·기기·시각)를 제거**하고,
  긴 변을 1280px 이하로 줄입니다. → `web/src/lib/image.ts`
- API 키는 **서버 환경변수에만** 두고 브라우저로 내려보내지 않습니다.
  브라우저는 자체 서버의 `/api/analyze` 만 호출합니다.
- 서버는 요청 본문을 로깅하지 않습니다. 오류 시에도 오류 코드만 남깁니다.
- 공유 카드에는 손톱 사진이 들어가지 않고 요약만 담깁니다.
- 프로필 화면에서 사진만 또는 전체 기록을 한 번에 삭제할 수 있고,
  "사진 저장하기"를 끄면 결과만 남고 사진은 저장되지 않습니다.

## 실행

```bash
npm install
cp .env.example .env        # ANTHROPIC_API_KEY 를 채워 넣으세요
npm run dev                 # 서버(8787) + Vite 개발 서버(5173)
```

브라우저에서 http://localhost:5173 을 엽니다.

### 프로덕션

```bash
npm run build               # 타입 검사 후 dist/ 로 번들
npm start                   # 같은 서버가 API 와 dist/ 를 함께 서빙 (기본 8787)
```

### 데모 모드

`ANTHROPIC_API_KEY` 가 없으면 샘플 결과로 동작해 UI를 그대로 확인할 수 있습니다.
이때 화면과 응답 양쪽에 데모 표시가 붙습니다. `ALLOW_DEMO_FALLBACK=false` 로 끌 수 있습니다.

### 스모크 테스트

```bash
npm start                   # 다른 터미널에서
npm run smoke               # 업로드 → 분석 → 공유 카드 → 기록까지 한 번 돌려보고 스크린샷 저장
```

## 분석 요청

`server/analyze.ts` 가 `claude-opus-5` 에 이미지와 함께 요청을 보내고,
구조화된 출력(`output_config.format`)으로 정해진 형태만 돌려받습니다.

- 시스템 프롬프트는 요청마다 동일하며 프롬프트 캐싱이 걸려 있습니다.
- 정책상 거절되면 같은 호출 안에서 대체 모델로 재시도합니다
  (`fallbacks: "default"`). 체인 전체가 거절하면 사용자에게 다시 찍도록 안내합니다.
- 모델이 6개 항목을 빠뜨리거나 순서를 바꿔도 서버에서 보정합니다.

## 구조

```
shared/analysis.ts     화면과 서버가 함께 쓰는 타입·라벨 (의존성 없음)
server/schema.ts       모델 출력 스키마 (zod, 서버 전용)
server/prompt.ts       시스템 프롬프트
server/analyze.ts      Claude 호출과 오류 매핑
server/index.ts        API 프록시 + 정적 파일 서빙
web/src/lib/           이미지 전처리, 로컬 저장소, API 클라이언트, 공유 카드 렌더링
web/src/screens/       홈 / 스캔 / 결과 / 기록 / 프로필
web/src/components/    공용 UI, 항목 목록, 팁, 추이 차트, 탭바, 아이콘
```
